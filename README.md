# OBS Skorbord

OBS Studio (31+) için skorbord eklentisi.

- **Skorbord kaynağı:** kendi skorbord görselinizi seçin; takım adları, skorlar ve periyot görselin üzerindeki yerlerine yazılır.
- **Skorbord paneli:** OBS içinde takım adları, − / + / +2 / +3 butonları, periyot.
- **Kısayol tuşları:** Ayarlar → Kısayollar → "Skorbord: …"

## İndirme

[Releases](../../releases/latest) sayfasından `obs-skorbord-windows.zip` dosyasını indirin, zip'ten çıkartıp `KUR.bat` dosyasına çift tıklayın.

Her `main` dalına gönderimde GitHub Actions Windows sürümünü otomatik derler.
